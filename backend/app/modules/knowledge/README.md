# knowledge

平台知识库模块。

这个模块负责把 `Obsidian` 等知识源同步成平台运行时知识数据，并提供统一检索能力给接待层、调度层等上游模块使用。

## 职责

- 管理通用知识库与租户专用知识库的注册关系
- 支持“平台托管 / 外部接入”两种知识仓接入方式
- 平台托管知识仓自动生成租户目录，并支持 Markdown 文件导入
- 外接知识仓支持目录可达性与 Markdown 扫描校验
- 同步外部知识源到平台内部文档与切片存储
- 提供统一的知识检索与命中格式化能力
- 向接待层输出可注入 `Hermes` 的 `knowledge_hits`
- 提供知识同步、检索、命中日志的可观测接口

## 边界

- 不负责知识内容编辑，知识编辑在 `Obsidian` 等外部工具完成
- 不负责接待逻辑，接待逻辑仍归 `reception`
- 不负责 Agent 配置，Agent 接入仍归 `agent_config`
- 不负责租户画像与长期记忆，画像与记忆仍归 `organization`

## 目录说明

- `api`：知识库对外接口层
- `application`：知识同步、解析、检索、注入等应用服务
- `schemas`：知识库模块数据模型
- `storage`：知识文档、chunk、同步任务、检索日志存储抽象
- `adapters`：外部知识源适配器，首版用于 `Obsidian` 本地文件系统
