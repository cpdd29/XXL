# 接入层模块（intake）

本模块用于承载“接入层运营视图”，聚焦以下内容：

1. 接入层 Agent 实时状态（Hermes 接待、安全监听、渠道入口相关）
2. 客户准入执行态（已服务、待核验、受限）
3. 客户准则配置摘要（模板必填项、生效租户策略）
4. 接入事件流（接待、拦截、转任务、任务信号）

## 目录约定

- `pages/*.tsx`：接入层页面实现
- `hooks/*.ts`：接入层数据访问逻辑（如需）

## 边界

- 本模块以“运营可视化”为主，不直接承担准入规则写入。
- 准入规则配置仍在 `settings/admission-template` 页面。
- 当前接待层不再提供“转人工”能力，只保留“继续接待 / 转任务”两种正式结果。
